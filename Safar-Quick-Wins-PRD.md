# SAFAR — Quick Wins PRD (v1.2)
### WhatsApp Share · PDF Download · Budget Split · Booking Links
### Frontend-only — zero backend changes, existing data 100% safe

---

## 0. Golden Rule — Current data na bigde

1. **Koi backend change nahi.** No new endpoint, no schema change, no
   request/response change. Ye saare features EXISTING plan JSON ko read
   karke kaam karte hain — jo already `/result` page pe render ho raha hai.
2. **Additive only**: naye buttons/components sirf add honge; kisi existing
   component ka props/structure nahi tootna chahiye.
3. **Defensive rendering** (existing rule follow karo): agar plan JSON me
   koi field missing hai — jaise `costs` khali — toh us feature ka button
   **hide** ho jaye, error na aaye.
4. Har feature ke baad `npm run build` + ek full journey test
   (plan → result → save → trips) — kuch bhi toota toh turant revert.

## 1. WhatsApp Share 🟢

**Kya**: Result page pe "WhatsApp pe share karo" button — poora plan ka
summary text WhatsApp me chala jaye.

**Kaise (client-side only):**
```js
const shareText = `🧳 *Safar — ${destination} Trip Plan*
📍 ${origin} → ${destination} | ${days} din | ${travellers} log

🚌 Mode: ${modeRecommendation.chosen} — ${modeRecommendation.reason}

🗺️ Route:
${route.map(r => `• ${r.from} → ${r.to} (${r.km} km, ${r.hours}h)`).join("\n")}

💰 Per person: ₹${perPersonCost.min}–₹${perPersonCost.max}
💵 Total: ₹${totalCost.min}–₹${totalCost.max}

✅ Top checklist:
${checklist.slice(0,4).map(c => `• ${c}`).join("\n")}

Plan banaya: safar-ka-link (yaha apna site URL)`;

window.open(`https://wa.me/?text=${encodeURIComponent(shareText)}`, "_blank");
```

**Spec:**
- Button Result page ke action bar me — WhatsApp green (#25D366) pill,
  WhatsApp icon (lucide `MessageCircle` ya official SVG)
- Saath me ek "Copy text" secondary option — desktop/logic fix users ke liye
- Text 1 WhatsApp message me fit ho (4000 char limit se door rahe —
  dayPlan details mat bhejo, sirf titles)
- Dark mode variant zaroori

## 2. PDF Download 📄

**Kya**: Result page se branded itinerary PDF download.

**Kaise**: `jspdf` package, client-side generate. **Koi server nahi.**

**PDF layout (single column, clean):**
```
Page 1: Header band (accent #ff6b35) me "SAFAR" wordmark + trip title
  "Delhi → Manali • Friends Trip"
  Summary + mode recommendation box
  Route table (from | to | km | hours)
Page 2 (agar data ho): Costs table (item | min | max) + total row
  (per person bold, accent color)
  Day-wise plan (day number + title + details, details 2 lines max)
  Checklist + tips, bullet points me
Footer har page pe: "Generated by Safar — Har Safar. Perfectly Planned."
  + page number
```

**Spec:**
- Button: action bar me "Download PDF" (lucide `Download` icon)
- Fonts: PDF me default helvetica — Inter embed mat karo (file size + complexity)
- `tripId` filename me: `safar-delhi-manali-<shareId>.pdf`
- Empty sections skip karo — blank page kabhi nahi
- Fallback: jsPDF fail ho toh browser print dialog (`window.print()`)

## 3. Budget Split 💸

**Kya**: Cost breakdown section ke neeche expandable "Split the bill" panel.

**Features:**
1. **Equal split** (default): per-person amount already `perPersonCost`
   me hai — bade numbers me dikhao + "Copy list" button:
   `Harsh: ₹3,250 · Rahul: ₹3,250 · ...` (naam editable list se)
2. **Custom split**: har member ka naam + amount field; total mismatch
   pe live warning — "₹X bacha hai" / "₹X zyada hai"
3. Members list localStorage me save (per trip), defaults "Traveller 1..N"
4. sab client-side — koi API call nahi

**Spec:**
- Panel `CostBreakdown` ke turant neeche, chevron toggle (0.3s height animation)
- Apple-style inputs — white bg, 12px radius, hairline border
- Numbers `toLocaleString('en-IN')` formatting (₹12,500 style)

## 4. Booking Deep-Links 🔗

**Kya**: Plan ke transport/cost items ke saath one-click booking/search
links — revenue ka rasta (affiliate baad me).

**Link targets (URL templates, sab public search pages):**
| Plan item | Link | Template |
|---|---|---|
| Bus | RedBus | `https://www.redbus.in/bus-tickets/<origin>-to-<destination>` (slugified, lowercase) |
| Train | IRCTC | `https://www.irctc.co.in/nget/train-search` (deep link unreliable — landing page hi behtar) |
| Flight | Google Flights | `https://www.google.com/travel/flights?q=Flights%20from%20<origin>%20to%20<destination>` |
| Hotels | Booking.com | `https://www.booking.com/searchresults.html?ss=<destination>` |

**Spec:**
- Buttons cost items ke rows me right side — chhote pill buttons,
  external-link icon, `target="_blank" rel="noopener noreferrer"`
- `modeRecommendation.chosen` ke hisaab se uska button **highlighted**
  (accent border), baaki muted — user ko clear direction mile
- Kabhi koi link force mat karna — cities slug me convert na ho paye toh
  button hide karo (defensive rule)
- **Affiliate ready**: link builder ek utility function me rakho
  (`buildBookingLink(type, origin, destination)`) — baad me affiliate
  ID bas isi function me append hogi, code jahan-jahan faila na ho
- City names space/uppercase clean karo: "New Delhi" → `new-delhi`
